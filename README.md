# Sayan — Creative Portfolio

A premium, interactive, single-page portfolio website built for a photographer and visual artist. Designed with a sleek dark aesthetic, glassmorphism UI elements, smooth scroll animations, and a rich user experience.

## ✨ Features

- **Dark Theme & Glassmorphism**: Premium deep aesthetic with translucent overlays and a concrete wall texture backdrop.
- **Scroll Animations**: Dynamic reveal and scale elements powered by Intersection Observer API.
- **Parallax Background**: Smooth 3D-depth parallax effect on scroll.
- **Dynamic Lighting**: Four corner ambient lights plus section-wise glowing lights that transition smoothly.
- **Custom Cursor**: Luxury trailing dot cursor with a responsive glass outline and hover scale effects.
- **Portfolio Grid**: Dynamic 3-column responsive grid with interactive category filters.
- **Client Reviews Slider**: Systematic one-by-one auto-scrolling testimonial slider with manual dot navigation.
- **Interactive UI**: Pop-up floating panels, premium text selection color, and fully responsive layout.

## 🚀 Getting Started

This is a vanilla web project built with pure HTML, CSS, and modern JavaScript. No complex build tools are required.

### Prerequisites (Optional)

You can run this simply by opening `index.html` in your web browser. However, for the best development experience (especially for avoiding CORS limitations when loading local assets), it's recommended to run a local development server.

If you have [Node.js](https://nodejs.org/) installed, you can use the included standard `package.json` scripts.

### Installation & Run

1. Clone or download to your local machine.
2. Open a terminal in the project directory.
3. Run the development server (requires Node/npx):

```bash
# Serve the folder explicitly
npm start

# OR run with live-reloading (Browser-Sync)
npm run dev
```
